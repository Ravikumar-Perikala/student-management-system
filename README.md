Student Management System

A simple Student Management System developed using Python. This project uses a text file (student.txt) to store and manage student information.

Features

The program provides the following options:

Write Student – Add student details to the file.
Display Students – Display all stored student records.
Search Students – Search for a student by name.
Count Students – Count the total number of students.
Exit – Exit the program.
Student Information

The following details are stored for each student:

Student ID
Student Name
Course
Fee
